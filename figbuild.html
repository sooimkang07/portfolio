Overview

This case study is in progress.

FigBuild is a design-to-build tooling project exploring how Figma's plugin ecosystem can better serve developers who are actively constructing design systems. The full case study is being documented as the project develops — check back soon.

FigBuild — coming soon

Problem

Figma is built for designers. Builders are an afterthought.

When developers and designers collaborate in Figma, the handoff process creates friction that is well-documented but poorly solved. FigBuild asks: what if the tool met builders where they already are — inside Figma itself — rather than routing them through a separate inspection layer?

Pain Point 1

Dev Mode surfaced properties without meaningful context — tokens, component hierarchy, and intent were all invisible

Pain Point 2

No way to annotate "build decisions" — constraints, edge cases, responsive rules — directly on the design file

Pain Point 3

Component variants required verbal explanation outside the tool; the spec was always one step behind the design

Research

Understanding the handoff breakdown

Early research involved shadowing three engineering teams as they received and implemented design files. The most consistent finding: engineers spent 30–40% of implementation time on clarification — either asking the designer or reverse-engineering intent from incomplete specs.

Research synthesis — handoff friction map

Solution

A build-intent layer, native to the Figma canvas

FigBuild is a Figma plugin that lets designers attach structured build notes directly to frames, components, and variants. Notes are categorized — layout rules, token references, interaction specs, edge cases — and surfaced contextually when an engineer enters Dev Mode on that frame.

Core Flows

Two primary user journeys

Designer: annotating build intent

Select any frame or component, open FigBuild, and attach a structured note. Categories keep annotations consistent across team members and easy to filter.

Designer flow — annotation panel

Engineer: reading build context

In Dev Mode, a FigBuild sidebar panel shows all annotations attached to the selected frame, grouped by category with inline token references that copy to clipboard on click.

Engineer flow — Dev Mode panel

Reflection

In progress

This project is actively being developed and tested with design teams. Reflection and outcomes will be documented once a full validation cycle is complete.

The core hypothesis: the best handoff tool is one that makes the designer's thinking legible without requiring them to leave their existing workflow. Testing will validate whether that holds.
