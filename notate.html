Chrome extension · 0→1 · 2026

Notate is a 0→1 Chrome extension I designed and built to save and revisit thoughts right where they happen on the web.

Role
Product Designer
Engineer (solo)
Scope
Problem framing
Product
Build
Launch
Platform
Chrome extension
Status
Live on the Chrome Web Store

Problem

We save the page, but what we meant to keep was a thought.

Something on a page sparks an idea. Tabs, bookmarks, and screenshots hold on to the page and drop the idea, so when you come back, you remember saving it but not why.

Solution

Notate saves the thought where it happened, and brings you back to it.

A note pinned to any headline, image, or button stays with its page, sorted by project, so weeks later it still makes sense and is one click away.

Research

Everyone saved the page. No one saved the why.

I interviewed 4 people who save things from the web every week. All of them relied on the same three workarounds, and each one fixed the last one’s problem while creating a new one.

  1. 01 · Keep tabs open

    Buried
    “I have forty tabs open and I’m scared to close any of them.”

  2. 02 · Bookmark it

    Context-less
    “I open the folder and have no idea why I saved half of these.”

  3. 03 · Screenshot it

    Disconnected
    “The screenshot’s in one app and the page is lost somewhere in my history.”

How might we

make a saved thought as useful weeks later as it was in the moment?

Design

One loop: annotate, organize, return.

Annotate

Pin the thought to the element that sparked it.

Click New, pick any headline, image, or button, and type. Save, and the note is pinned right beside it.

Decision

Attach the note to the element, not the page.

A note floating beside the page drifts away from what it’s about. Anchored to an element, it scrolls with it, so it’s always clear what the note refers to. Saved notes stay draggable, in case the automatic placement covers something.

Organize

File notes by project, not by tab.

Folders span websites, so one project collects every note from everywhere it was researched, and nothing has to stay open to be kept.

Decision

Organize by note, not by page.

One page can hold notes for different projects: a pricing table for research, a headline for design reference. So folders apply to each note, and the side panel previews every note in its folder color, skimmable before anything is opened.

Return

Come back to the exact spot.

Open a note from the side panel. Notate reopens the page, or reuses the tab if it’s already open, and lands on the element.

Decision

Come back to notes without re-entering annotation mode.

Revisiting a page shows its notes in a read-only preview, so hover highlights never get in the way of reading or scrolling. Opening a note from the side panel scrolls its element to the center of the viewport.

Design · First run

Setup ends with a real note, not a demo.

Chrome hides new extensions behind the puzzle-piece menu, so an install can be forgotten before the first note. The welcome page checks off each step only when Chrome confirms it, and finishes with a real note on a real page. No sample data is added to your library.

Branding

Quiet by design, so the webpage stays the loudest thing on screen.

White utility UI with warm ink and system type. The only color is the organization you add: six folder pastels at the same lightness, so no project looks louder than another.

Build

I built Notate myself with Claude Code, and kept a decision log so the agents built what I decided.

Notate runs inside Chrome’s extension platform: a side panel, scripts that draw notes onto any webpage, local storage, and only the permissions it needs. I designed it and built it with coding agents, then shipped it to the Chrome Web Store.

Webpages change after you annotate them, so I designed for the element disappearing. The note stays near where you left it, with a warning, and Notate never guesses at a different element to attach it to. Onboarding follows the same rule: no tracking and no network calls. Nothing leaves your browser.

Launch

Designing how Notate gets found.

The store listing is most people’s first screen. Each card shows one step of the loop on a real page with a single line of copy, so the product is understood before it’s installed.

Reflection

Shipped. Next, prove it beats the workaround.

Notate is days old. With no advertising, it picked up 13 installs in its first few days, and no one has uninstalled it. Reviews and real usage are still to come. Next, I’ll watch three people run the full loop without coaching and time how fast they find a week-old note against their current workaround. After that: letting people re-attach a note when its element disappears from a redesigned page.
